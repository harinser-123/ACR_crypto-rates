# ACR — API Crypto Rates

Учебный проект для итоговой аттестационной работы: приложение на Python с графическим интерфейсом для отображения курсов криптовалют.

## Цель проекта
Создать приложение, которое:
- Получает актуальные данные о криптовалютах из открытого API (CoinGecko).
- Отображает курсы в удобном графическом интерфейсе (Tkinter).
- Автоматически обновляет данные без перезапуска программы.

## Стек технологий
- **Python 3.x** — язык реализации.
- **Tkinter** — графический интерфейс (окна, виджеты, таймеры).
- **requests** — HTTP-запросы к API.
- **Git** — контроль версий.
