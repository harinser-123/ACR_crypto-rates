# ACR_crypto-rates

Учебный проект: приложение для отображения курсов криптовалют с конвертацией в рубли.

## Цель проекта
Разработать приложение с графическим интерфейсом на Python (Tkinter), отображающее текущие курсы популярных криптовалют и конвертирующее их в рубли с использованием открытых API.

## Функционал
- Отображение курсов BTC, ETH, SOL, ADA, DOGE и других монет.
- Конвертация цен в рубли (USD → RUB).
- Обновление данных без зависания интерфейса (многопоточность).
- Добавление и удаление монет из списка наблюдения.
- Каталог монет для удобного выбора.
- Обработка ошибок API и запасной курс рубля при недоступности источника.

## Используемые технологии
- Python 3.13
- Tkinter (графический интерфейс)
- requests (работа с API)
- threading (неблокирующее обновление данных)

## API
- Криптовалюты: Bybit, MEXC, KuCoin (без API-ключей).
- Курс USD/RUB: kurs-rublya.ru.

## Особенности реализации
- Многоисточниковость: если одна биржа не отвечает, данные берутся с другой.
- Fallback-курс: при ошибке получения курса рубля используется запасное значение.
- Неблокирующий интерфейс: запросы вынесены в отдельный поток, чтобы окно не «зависало».
