# ACR_crypto-rates — приложение для отображения курсов криптовалют

**ACR** (API Crypto Rates) — десктопное приложение на Python с графическим интерфейсом, которое показывает актуальные курсы популярных криптовалют к доллару США и автоматически пересчитывает их в рубли.

## 🎯 Цель проекта

Разработать приложение для итоговой аттестационной работы, которое:
* отображает курсы криптовалют в реальном времени;
* позволяет пользователю управлять списком отслеживаемых монет;
* показывает цены в USD и RUB;
* имеет адаптивный интерфейс, который корректно масштабируется при изменении размера окна.

## ✨ Возможности приложения

* **Отображение курсов** — актуальные цены на Bitcoin, Ethereum, Solana, Cardano, Dogecoin и другие монеты.
* **Пересчёт в рубли** — отдельный запрос к API для получения курса USD/RUB и автоматический расчёт стоимости каждой монеты в рублях.
* **Управление списком монет**:
  * просмотр полного каталога доступных монет;
  * добавление монет в отслеживание из каталога;
  * удаление монет из списка отслеживания.
* **Автообновление** — курсы обновляются каждые 2 минуты без участия пользователя.
* **Адаптивный интерфейс** — при изменении размера окна списки и таблица растягиваются, сохраняя удобную компоновку.

💡 Как работает добавление монет
Пользователь открывает каталог монет справа.
Выбирает нужную монету в списке.
Нажимает кнопку «Добавить выбранную».
Приложение:
проверяет, нет ли этой монеты уже в отслеживании;
добавляет монету в список «Текущие монеты»;
сразу запрашивает актуальный курс и отображает его в таблице.
Аналогично работает удаление: пользователь выбирает монету из «Текущих» и нажимает «Удалить выбранную» — монета исчезает из списка и таблицы.

 Автообновление и расчёт в рублях
Приложение делает два независимых запроса:

Запрашивает котировки выбранных монет у биржи (приоритет — Bybit, с запасными вариантами MEXC и KuCoin).
Отдельно запрашивает курс пары USDTRUB у Bybit.
После получения данных цена в долларах умножается на курс рубля, результат форматируется с разделителями тысяч и символом ₽ (например: 1 234 567,89 ₽).

Обновление происходит автоматически каждые 2 минуты. Также можно обновить данные вручную кнопкой «Обновить курсы».

 История разработки (этапы)
Проект разрабатывался поэтапно с фиксацией каждого значимого изменения в Git:

Базовая версия — простой интерфейс и получение курсов.
Два столбца — разделение на «Текущие» и «Каталог», логика добавления/удаления.
Адаптивная сетка — полный переход на grid, растягивание колонок при изменении размера окна.
Рубли и двойной расчёт — добавление столбца «Цена (RUB)», отдельный запрос курса USD/RUB, улучшенное форматирование.
Финальные доработки — проверка дублей, мгновенное обновление списка и курса после добавления монеты.
