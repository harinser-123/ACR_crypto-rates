# ACR — API Crypto Rates

Учебный проект для итоговой аттестационной работы: настольное приложение на Python с графическим интерфейсом для отображения актуальных курсов криптовалют.

## Цель проекта
Создать приложение, которое:
- Получает актуальные курсы криптовалют из открытого API CoinPaprika.
- Отображает их в удобном графическом интерфейсе (Tkinter).
- Автоматически обновляет данные без перезапуска программы.

## Стек технологий
- **Python 3.x** — язык реализации.
- **Tkinter / ttk** — графический интерфейс (окно, метки, кнопка).
- **requests** — HTTP-запросы к API.
- **Git** — контроль версий.
