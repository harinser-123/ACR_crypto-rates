ACR — API Crypto Rates
Учебный проект для итоговой аттестационной работы: настольное приложение на Python с графическим интерфейсом для отображения актуальных курсов криптовалют.
Цель проекта
Создать приложение, которое:
Получает актуальные курсы криптовалют из открытых API бирж.
Отображает их в удобном графическом интерфейсе (Tkinter).
Автоматически обновляет данные без перезапуска программы.
Позволяет настраивать список монет: искать, добавлять и удалять их прямо в приложении.
Стек технологий
Python 3.x — язык реализации.
Tkinter / ttk — графический интерфейс (окно, таблица, списки, кнопки).
requests — HTTP-запросы к API бирж.
Git — контроль версий.

Источник данных
Изначально планировался агрегатор CoinPaprika, но он оказался недоступен из сети. Были проверены альтернативы: CoinLore (недоступен), CoinMarketCap (лимит анонимного доступа, требуется регистрация), CryptoCompare (объединён с CoinDesk, требует API-ключ), OKX и Gate.io (слишком большие ответы целиком).
Итоговое решение — публичные API бирж Bybit → MEXC → KuCoin точечными запросами по одной паре:
ключи и регистрация не нужны;
ответы компактные — меньше риск тайм-аутов на медленной сети;
отказоустойчивость: биржи перебираются по очереди в списке `PROVIDERS`, если одна не отвечает, данные берутся у следующей.
Возможности приложения
Таблица курсов выбранных монет в долларах США.
Автообновление каждые 2 минуты и ручная кнопка «Обновить курсы».
Поиск монет по названию или тикеру (локальный словарь популярных монет).
Добавление и удаление монет в списке отображения.
